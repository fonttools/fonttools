#####################################################
psCharStrings: Tools for working with CharString data
#####################################################

.. currentmodule:: fontTools.misc.psCharStrings

CFF DICT real operands are serialized with up to 14 significant decimal
digits, preserving values such as nine-digit ``CIDFontVersion`` numbers.
This uses the encoder's historically documented macOS compatibility cap.
